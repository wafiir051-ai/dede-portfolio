# Portofolio Dede Kismantoro

Situs portofolio desainer grafis. React + Vite, dengan komponen React Bits (CircularGallery, TiltedCard, Stack, ScrollVelocity, DotGrid).

## Jalankan

```bash
npm install
npm run dev
```

## Ubah kontak

Edit `src/config.js` (WhatsApp, Telegram, Instagram, email). Kolom yang kosong tidak ditampilkan.

## Tambah atau ganti karya

Gambar ada di `public/assets/work/` dan `public/assets/sketch/`. Daftarnya di `src/works.json`.
